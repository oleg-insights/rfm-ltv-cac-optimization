# LTV/CAC оптимизация: снижение расходов и анализ лояльности

**Задача**: 

Снизить неэффективные расходы на привлечение клиентов.

**Ключевой вывод**: 

LTV чемпионов в 9.34 раза выше среднего.

**Гипотеза**:

Часть средств из привлечения новых клиентов следует перенаправить на удержание лояльных. 

**A/B-тест**:

Для теста перераспределения бюджета с приростом конверсии с 66% до 71% требуется выборка 2818 пользователей суммарно на две группы.

**Визуализация**:

Карта Heatpam.

**Используемые методы**:
- Разбиение клиентов на сегменты RFM
- Оценка клиентов по балльной шкале
- Расчет LTV
- Расчет базовой конверсии и размера выборки для A/B-теста

**Инструменты**:
- Python (Pandas)
- Seaborn
